# FloodRoute Web Frontend

> **Production Deployment:** [https://flood-route-six.vercel.app/](https://flood-route-six.vercel.app/)  
> **API Backend:** [https://floodroute.onrender.com/](https://floodroute.onrender.com/)

Next.js 16 (App Router, TypeScript, Tailwind CSS, MapLibre GL) frontend for FloodRoute — flood-aware ambulance navigation and decision support for Mumbai.

## Local Development

```bash
# Install dependencies
npm install

# Run the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Production Build

```bash
npm run build
```

Generates optimized static pages in `web/out/`.
